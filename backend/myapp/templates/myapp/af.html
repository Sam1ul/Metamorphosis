🔑 Authentication Failures (Broken Authentication)

Authentication failures occur when systems improperly implement authentication mechanisms, allowing attackers to compromise passwords, session tokens, or user identities. This can lead to unauthorized access to user accounts.

What are Authentication Failures?

Authentication failures happen when applications fail to correctly verify user identity. Weak login systems, poor session management, and insecure password handling are common causes.

Memory Trick: Weak login = easy account takeover.

Why It’s Dangerous

  • Account takeover
  • Unauthorized access to sensitive data
  • Privilege escalation
  • Identity theft
  • Loss of user trust

Common Causes

  • Weak or predictable passwords
  • No account lockout after failed attempts
  • Session IDs exposed in URLs
  • No multi-factor authentication (MFA)
  • Poor session management

Examples

Example 1: Weak Password

password = "123456"

Example 2: No login attempt limit

User can try unlimited passwords → brute force attack

Example 3: Session in URL

http://example.com/dashboard?sessionid=abc123

Possible Attacks

  • Brute-force attack
  • Credential stuffing
  • Session hijacking
  • Password guessing

Prevention

  • Use strong password policies
  • Implement account lockout after failed attempts
  • Use Multi-Factor Authentication (MFA)
  • Secure session management
  • Use HTTPS for all authentication processes

Best Practices

  • Hash passwords using bcrypt or Argon2
  • Expire sessions after inactivity
  • Use secure cookies (HttpOnly, Secure)
  • Monitor login attempts
  • Avoid exposing session IDs in URLs

For Exam Writing

Authentication failure is a vulnerability where improper authentication mechanisms allow attackers to gain unauthorized access to user accounts.

Summary

Authentication is the first line of defense. Weak authentication mechanisms can lead to complete system compromise. Strong password policies, MFA, and secure session handling are essential for protection.
